# PuntGo Design System Rules

These rules must be followed strictly for all UI design and code generation for the PuntGo app.

## Colors
- **Primary Color:** #1B7D3C (Forest Green)
- **Secondary Color:** #FFFFFF (White)
- **Accent Color:** #F5A623 (Orange - for ratings, highlights, primary calls to action)
- **Background:** #F8F8F8 (Light Gray - for main app backgrounds to keep it clean)
- **Text Primary:** #1A1A1A (Near Black - for readability)
- **Text Secondary:** #6B6B6B (Gray - for subtitles and descriptions)

## Typography & UI Elements
- **Font:** Clean sans-serif (Inter, SF Pro, or default system sans-serif)
- **Corner Radius (Cards):** 12px
- **Corner Radius (Buttons):** 25px
- **Style:** Modern, clean, minimal with green accents. Do not clutter the UI.

## Brand Elements
- **App Name:** PuntGo
- **Tagline:** Food Delivery & Taxi | Fast • Easy • Reliable
- **Location Context:** Garowe, Puntland, Somalia
- **Phone Format:** +252

## Execution Rules
- Always use the defined colors. Do NOT invent new colors.
- Always apply the correct border radiuses to cards and buttons.
- For high-fidelity screens, always aim for a pixel-perfect layout similar to an iPhone 14 Pro style.
